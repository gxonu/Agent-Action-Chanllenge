## 주제선정 배경

현대 AI Agent 시스템은 단순 응답 생성을 넘어 사용자 요청에 따라 어떤 행동을 수행할지 판단하는 방향으로 발전 중이다. 복잡한 생성이나 장문 추론 이전에, **현재 맥락에서 어떤 작업을 선택하고 실행할지를 빠르게 결정하는 단계**가 매우 중요한 상황이다.

LLM에 전적으로 의존하는 방식은 비용·지연 측면의 한계가 있으므로, 실제 시스템에서는 LLM 호출 전에 **경량 의사결정 모델을 별도로 두어, 행동 분기나 의도 판단을 우선 처리하는 구조**가 중요하다.

---

## 목적

제한된 자원 환경에서 안정적으로 동작하는 **경량·고속 의사결정 AI 모델**을 설계하고 구현하는 데 있다. 참가자는 AI Agent의 구성 요소와 실제 판단·실행 구조를 이해할 수 있다.

---

## 주제

**AI Agent 행동(Action) 의사결정 예측 챌린지**

---

## 문제 설명

참가자는 AI 코딩 에이전트 세션의 상태 데이터를 바탕으로 에이전트가 다음에 수행할 행동을 **14개 클래스 중 하나로 예측**해야 한다.

### 입력 데이터 구성

- **current_prompt** — 현재 사용자 발화
- **history** — 대화·행동 이력
- **session_meta** — 세션 메타정보 (요금제, 잔여 토큰 예산, 작업공간 상태 등)

### 예측 대상

파일 읽기·검색·수정, 셸 명령 실행, 테스트 실행, 사용자 질문 등 에이전트의 주요 행동

### 평가지표

14개 클래스에 대한 **Macro-F1**
