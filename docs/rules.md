## 평가 서버 환경 (사전 설치 패키지)

> 출처: DACON rules 페이지 "실행 환경" 섹션 (2026-07-05 확인). 로컬 문서 초판에 누락되어 보강.

**서버 사양**

| 항목 | 값 |
|------|------|
| OS | Ubuntu 22.04.5 LTS |
| GPU | NVIDIA T4 (VRAM 16GB) |
| CPU | 3 vCPU |
| RAM | 12GB |
| Python | **3.11.15** |
| CUDA | **12.8** |
| 인터넷 | 비활성화 (설치 단계만 허용) |

**사전 설치 주요 패키지 (버전 고정)**

| 패키지 | 버전 |
|--------|------|
| torch | **2.7.1+cu128** |
| transformers | **4.46.3** |
| numpy | **1.26.4** |
| pandas | **2.0.3** |
| scikit-learn, scipy, tqdm 등 | 다수 포함 |

**⚠️ 버전 규칙 (원문)**
> "버전이 명시된 아래의 패키지(라이브러리)에 한해서는 다른 버전을 사용할 때 설치 에러가 발생할 수 있으므로"

- 즉 고정 버전 패키지를 `requirements.txt`로 **다른 버전 지정 시 설치 실패 가능** — 금지는 아니고 **리스크 경고**.
- ModernBERT(tf≥4.48)·Qwen3(tf≥4.51) 등 상위 transformers 요구 모델은 기본 4.46.3에서 로드 불가.
  → **상위 버전을 `requirements.txt`에 명시해 업그레이드 시도는 가능**하나, torch 2.7.1 호환 + 10분 설치 안에 완료돼야 함. **probe 제출 1회로 실측 검증 필요** (미검증).
- 우리 개발 env(`intern_aichallenge`)는 **이 스펙을 미러링**해서 train/serve 불일치를 차단한다.
