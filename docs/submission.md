# 제출 방식 상세

> 출처: https://dacon.io/competitions/official/236694/overview/rules

---

## 제출 방식: 코드 제출 대회

예측 결과 파일이 아닌 **추론 코드(script.py)와 학습된 모델을 제출(submit.zip)** 하는 방식이다.

---

## 필수 폴더 구조

```
submit.zip
├── model/              # 학습된 모델 파일
├── script.py           # 추론 코드
└── requirements.txt    # 필요 패키지 목록
```

---

## 실행 환경 (서버)

| 리소스 | 스펙 |
|--------|------|
| GPU | **T4 (16GB VRAM)** |
| CPU | 3 vCPU |
| RAM | 12GB |

---

## 실행 제약

| 항목 | 제한 |
|------|------|
| 추론 코드 실행 시간 | ≤ **10분** |
| 패키지 설치 시간 | ≤ **10분** |
| 제출 파일 용량 | ≤ **1GB** |
| 인터넷 접속 | **비활성화** (패키지 설치 외 외부 연결 불가) |
| 1일 최대 제출 횟수 | **10회** |

---

## 오프라인 환경 유의사항

- 패키지 설치 단계 이후에는 인터넷 사용이 불가하다
- 사전학습 모델을 사용할 경우 **`model/` 디렉토리에 미리 포함**시켜야 한다
- HuggingFace, PyTorch Hub 등에서 런타임에 다운로드하는 코드는 실패한다

---

## 활용 가능 항목

- **사전학습 모델 사용 허용**
- **외부 데이터 사용 허용**
- **외부 API 활용 허용** (단, 오프라인 환경에서 실행 가능해야 함)
- 유료 서비스 이용 시 참가자 부담
- 법적 제약 사항 확인 필수
- 사용한 주요 외부 요소의 출처와 활용 범위 기재 필수
